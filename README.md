# AHU-Math 📚

> 安徽大学数学科学学院学习资料整理与共享
> Anhui University · School of Mathematical Sciences

本仓库用于整理和共享 **安徽大学数学科学学院相关课程的学习资料、复习资料以及历年考试试卷**，希望能够为课程学习、期中期末复习以及知识查漏补缺提供一个相对集中、清晰、长期可维护的资料库。

目前仓库主要覆盖数学专业本科阶段的核心课程，目前包括：

**数学分析 / 高等代数 / 解析几何 / 概率论 / 数理统计 / 常微分方程 / 数值分析 / 复变函数 / 实变函数**

仓库仍处于不断完善过程中，欢迎大家通过 Issue 或 Pull Request 补充缺失资料、整理文件结构或修正错误。

## 📖 项目简介
为了方便各位学弟学妹更好的学习进步，特整理一份数学科学学院专业课资料库。

目前内容主要涵盖大一大二专业课的试卷及资料。

从24级开始，已经取消教考分离，期末不再是科大出卷,难度相比往年有所减小。因此部分专业课，考前找对方法突击，期末90+不是问题。

后续会持续更新其他专业课资料，以及保研资料和面经分享。

# 🚀 如何使用

## 方法一：直接在线查看

直接进入对应课程文件夹，根据课程名称、考试年份或者资料类型寻找需要的文件即可。

对于 PDF 文件，GitHub 通常可以直接进行在线预览。

---

## 方法二：下载整个仓库

点击仓库页面中的：

**Code → Download ZIP**

即可将全部资料下载到本地。

---

## 方法三：使用 Git 克隆

已经安装 Git 的同学可以运行：

```bash
git clone https://github.com/QWBO111/AHU-Math.git

cd AHU-Math
```

后续仓库更新后，可以使用：

```bash
git pull
```

获取最新内容。
